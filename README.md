# C Calculator

A basic command-line calculator developed using C programming.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Invalid operator handling
- Division-by-zero handling

## Concepts Used

- Variables
- Data types
- `printf()` and `scanf()`
- Arithmetic operators
- `switch-case`
- Conditional statements
- Basic error handling

## How It Works

The user enters:

1. First number
2. An arithmetic operator
3. Second number

The program performs the selected operation and displays the result.
